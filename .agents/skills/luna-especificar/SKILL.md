# Luna — Especificar

Recopila desde el pedido existente:

- objetivo;
- usuario;
- problema;
- alcance;
- exclusiones;
- flujo;
- funciones P0/P1/P2;
- casos borde;
- criterios de aceptación;
- riesgos.

Actualizar `PRODUCT_SPEC.md`.

No inventar requisitos innecesarios.
Marcar supuestos cuando falte información.
