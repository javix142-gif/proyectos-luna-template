# Luna — Release

Antes:
- working tree/diff revisado;
- versión definida;
- pruebas completas;
- build reproducible;
- secretos ausentes.

Generar:
- artefacto;
- checksum opcional;
- notas de versión;
- instrucciones de instalación;
- riesgos conocidos.

No desplegar a producción ni publicar stores sin autorización explícita.
