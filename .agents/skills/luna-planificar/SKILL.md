# Luna — Planificar

Para cada tarea:

- ID;
- objetivo;
- archivos o módulo;
- cambio esperado;
- dependencia;
- riesgo;
- prueba;
- condición de cierre.

Preferir tareas que puedan revisarse individualmente.
No mezclar feature, refactor y migración salvo necesidad técnica.
