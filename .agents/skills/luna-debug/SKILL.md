# Luna — Debug Sistemático

1. Reproducir.
2. Capturar error exacto.
3. Delimitar módulo.
4. Revisar cambios recientes.
5. Rastrear datos/estado.
6. Formular hipótesis.
7. Diseñar prueba para falsarla.
8. Corregir causa mínima.
9. Repetir reproducción.
10. Ejecutar regresiones.

Dos intentos fallidos obligan a detener parches y reanalizar.
