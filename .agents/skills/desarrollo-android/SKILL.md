# Desarrollo Android

Revisar:
- minSdk / targetSdk;
- permisos mínimos;
- Manifest;
- Gradle;
- arquitectura;
- ciclo de vida;
- navegación;
- estado;
- orientación/tamaños;
- errores de red;
- build debug;
- APK generado.

Nunca exponer keystore, passwords o claves de firma.
