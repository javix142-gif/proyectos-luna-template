# Luna — Review

No modificar.

Revisar:
- requisito;
- diff;
- bugs;
- regresiones;
- seguridad;
- manejo de errores;
- performance;
- compatibilidad;
- dependencias;
- tests;
- cambios extra.

Clasificar:
Crítico / Alto / Medio / Bajo.

Para cada hallazgo:
- archivo;
- evidencia;
- impacto;
- corrección mínima sugerida.
