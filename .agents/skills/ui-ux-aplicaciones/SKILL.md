# UI/UX de aplicaciones

Priorizar:
- jerarquía visual;
- legibilidad;
- consistencia;
- espaciado;
- estados vacío/carga/error;
- responsive/resize;
- accesibilidad básica;
- botones y acciones claras;
- feedback de usuario.

Antes de cambiar:
- inventariar funcionalidades existentes;
- mantenerlas;
- evitar rediseños fuera del alcance.

Validar visualmente y funcionalmente.
