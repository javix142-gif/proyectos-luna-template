# Luna — Implementar

Antes:
- leer AGENTS relevantes;
- leer PROJECT_STATE;
- leer tarea;
- inspeccionar código relacionado.

Durante:
- cambio mínimo;
- patrones existentes;
- sin refactor oportunista;
- sin dependencias injustificadas.

Después:
- pruebas;
- build/checks;
- diff;
- actualizar TASKS y PROJECT_STATE.
