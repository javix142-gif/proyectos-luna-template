# LUNA CORE

Contexto estable del framework PROYECTOS LUNA.

## Modo actual

GitHub Template / un proyecto por repositorio.

Cada repositorio generado desde el template representa UNA aplicación independiente.

## Política

Durante desarrollo normal:

- LEER: permitido.
- USAR: permitido.
- MODIFICAR: prohibido salvo orden explícita para actualizar el framework.

## Componentes

- `policies/`: reglas operativas.
- `templates/`: referencias para documentos de proyecto.
- `checklists/`: controles por tipo.
- `QUALITY_GATES.md`: condiciones de terminado.
- `WORKFLOW.md`: ciclo estándar.
- `ESCALATION.md`: protocolo anti-thrashing.

## Estado del proyecto

El contexto variable vive en la raíz:

- PRODUCT_SPEC.md
- TECH_SPEC.md
- TASKS.md
- PROJECT_STATE.md
- SESSION_SUMMARY.md
- PROJECT_META.json
