# Checklist Android / APK

- [ ] `gradlew test` o equivalente.
- [ ] build debug exitoso.
- [ ] APK generado.
- [ ] minSdk/targetSdk revisados.
- [ ] permisos mínimos.
- [ ] manifest revisado.
- [ ] sin claves de firma expuestas.
- [ ] orientación/tamaños relevantes probados.
- [ ] navegación principal probada.
- [ ] errores de red manejados.
- [ ] estado ante rotación/reinicio considerado si aplica.
