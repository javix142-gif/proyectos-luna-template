# Checklist Automatizaciones

- [ ] modo dry-run si el riesgo lo justifica.
- [ ] inputs validados.
- [ ] backups cuando aplica.
- [ ] errores recuperables registrados.
- [ ] reejecución segura/idempotencia considerada.
- [ ] no hay rutas hardcodeadas innecesarias.
- [ ] no se borran archivos sin confirmación.
- [ ] logs suficientes pero sin datos sensibles.
