# Política de dependencias

Antes de agregar una dependencia:

1. comprobar si el proyecto ya dispone de una solución;
2. justificar necesidad;
3. verificar mantenimiento y licencia;
4. revisar superficie de seguridad;
5. evitar paquetes redundantes;
6. registrar el cambio.

No actualizar masivamente dependencias salvo que la tarea lo requiera.
