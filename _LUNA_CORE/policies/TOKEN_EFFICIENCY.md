# Política de eficiencia de contexto

1. Contexto estable vive en archivos persistentes.
2. El prompt de tarea contiene solo contexto variable.
3. No pegar conversaciones completas.
4. Recortar logs.
5. Leer solo archivos relevantes.
6. Trabajar por módulos.
7. Actualizar `PROJECT_STATE.md`.
8. Evitar repetir reglas del `AGENTS.md`.
9. Pedir salidas breves durante exploración.
10. Dividir tareas grandes.
