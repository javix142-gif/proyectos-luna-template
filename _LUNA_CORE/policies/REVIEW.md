# Política de code review

Clasificar hallazgos:

- Crítico: seguridad, pérdida de datos, corrupción, despliegue o función central.
- Alto: bug probable, regresión importante o contrato roto.
- Medio: riesgo real no bloqueante, mantenibilidad o prueba faltante.
- Bajo: claridad, estilo o mejora menor.

Revisar:

- cumplimiento del requisito;
- cambios fuera de alcance;
- manejo de errores;
- validaciones;
- seguridad;
- compatibilidad;
- performance;
- concurrencia si aplica;
- duplicación;
- dependencias;
- tests;
- documentación;
- rollback.
