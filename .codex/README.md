# Configuración Codex

Este directorio contiene perfiles de agentes documentales y puede ampliarse con configuración específica del entorno que utilices.

Se evita fijar aquí parámetros de modelo que puedan cambiar entre versiones de Codex/Work.

El principio del workspace es:

- usar GPT-5.6 Luna;
- usar el máximo razonamiento disponible en la interfaz;
- roles separados para planificación, implementación, review, debugging y testing.
